# WinLocker

EN:  
Warning! This project is NOT malicious software! It was created EXCLUSIVELY for self-education and learning the WinAPI.  
The project is a Windows locker, but it DOES NOT encrypt any data and DOES NOT prevent the user from simply closing the window.
